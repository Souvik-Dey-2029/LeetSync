LeetSync

Sync your LeetCode submissions to your own GitHub repository.

1. Your GitHub OAuth App

LeetSync has no server of its own — every installation authenticates directly with GitHub using an OAuth App that you create and control. Nothing is sent to, or stored by, anyone other than you and GitHub.

  1. Go to GitHub → Settings → Developer settings → OAuth Apps and click New OAuth App.
  2. Fill in any Application name / Homepage URL you like.
  3. Set Authorization callback URL to https://github.com/ (not used for the device flow below, but GitHub requires a value).
  4. After creating the app, open Enable Device Flow and turn it on.
  5. Copy the generated Client ID and paste it below.
